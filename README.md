# Vitality — Daily Vitamin & Habit Tracker

Vitality is a modern, minimalist daily vitamin and habit tracker built with **React (Vite)**, **Tailwind CSS**, **Lucide React**, and connected directly to **Supabase (PostgreSQL)** via `@supabase/supabase-js`.

---

## ⚡ Tech Stack

- **Frontend**: React 18 + Vite
- **Styling**: Tailwind CSS (Minimalist neutral palette, emerald accent, responsive layout)
- **Icons**: Lucide React
- **Backend / Database**: Supabase (PostgreSQL) via `@supabase/supabase-js`
- **Device Scoping**: Client-side `localStorage` unique `device_id` isolation (no login required)

## 🚀 Supabase Setup

### 1. Database Table (`vitamins`)
In your Supabase project SQL editor, run:

```sql
CREATE TABLE IF NOT EXISTS public.vitamins (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  device_id TEXT NOT NULL,
  name TEXT NOT NULL,
  date DATE NOT NULL,
  time TIME NOT NULL,
  is_completed BOOLEAN DEFAULT FALSE,
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Index for high-performance device filtering
CREATE INDEX IF NOT EXISTS idx_vitamins_device_id ON public.vitamins(device_id);

-- If the table already exists, run this migration:
ALTER TABLE public.vitamins ADD COLUMN IF NOT EXISTS device_id TEXT;
CREATE INDEX IF NOT EXISTS idx_vitamins_device_id ON public.vitamins(device_id);

-- Enable Row Level Security (optional / based on your policy)
ALTER TABLE public.vitamins ENABLE ROW LEVEL SECURITY;

-- Allow read & write policy for public / anon access:
CREATE POLICY "Allow public access to vitamins" 
ON public.vitamins 
FOR ALL 
USING (true) 
WITH CHECK (true);
```

## 💻 Running the Application

```bash
# Navigate to the frontend directory
cd frontend

# Install dependencies (if not done)
npm install

# Start Vite dev server
npm run dev
```

Open **`http://localhost:5173`** in your browser. Each device/browser will automatically generate and store a persistent `vitality_device_id` in `localStorage`, keeping vitamin records completely isolated per device without needing an account or login screen!
